# Validacion rapida: Verguenza

1. Ejecutar `npm run build`.
2. Abrir la Isla Verguenza desde el mapa emocional.
3. Entrar en `Leer cuento`.
4. Avanzar por las seis paginas y comprobar que cada imagen se muestra completa.
5. Completar el cuento y confirmar que la recompensa, los puntos y el siguiente paso siguen funcionando.
6. Confirmar que los siete recursos de `public/images/stories/verguenza/` responden desde el servidor local.
7. Revisar `visual-checks/verguenza-contact-sheet.jpg` para continuidad de Vera, tono seguro y ausencia de texto o marcas.
